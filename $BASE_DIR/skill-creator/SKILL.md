# Skill Creator
## Structure
A skill must be in its own folder under `agent-core/skills/`.
It must contain a `SKILL.md` file.

## SKILL.md Template
```markdown
---
name: skill-name
description: Clear description of what the skill does and when it should be used.
---
# Skill Title
Instructions, examples, and guidelines for the agent.
```
