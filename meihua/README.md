# 梅花易数 · 寂 (Cyber Mei Hua Yi Shu)

基于中国传统数术“梅花易数”的时间起卦排盘程序。

## 核心特性
- **算法附灵**：严格遵循先天八卦数与时间卦位演化逻辑。
- **三卦同现**：自动生成本卦、互卦与变卦，完整揭示事物的起因、过程与结果。
- **金曜视觉**：采用 Dark Gold Cyber 风格，营造肃穆的数字占卜氛围。
- **深度演算**：30秒高逼格演算动画，模拟因果链条的实时同步。

## 部署说明
1.  在 GitHub 上创建新仓库。
2.  上传 `meihua_app.py` 和 `requirements.txt`。
3.  在 Streamlit Cloud 中连接仓库并部署 `meihua_app.py`。
